# Точка · локальный голосовой администратор

Рабочее русскоязычное приложение: WebRTC-звонок, чат, подтверждённая запись на услуги и кабинет оператора. STT, LLM и TTS работают локально, без платных модельных API. В комплекте — настоящие PostgreSQL и EspoCRM.

**Компания, услуги и начальный адрес вымышлены.** Текущий результат — проверенная локальная версия; полная внешняя приёмка G1–G3 из исходного плана ещё не завершена.

- [EspoCRM](http://127.0.0.1:18081/)
- [API](http://127.0.0.1:7860/docs)

На текущем Mac приложение установлено. Откройте `Start.command` или выполните:

```sh
.venv/bin/python scripts/run.py
```

Новая установка требует работающего Docker:

```sh
brew install python@3.12 llama.cpp whisper.cpp ggml rubberband
python3.12 scripts/setup.py
.venv/bin/python scripts/run.py
```

Установщик создаёт приватную `.env` со случайными паролями. `ADMIN_PASSWORD` — администратор кабинета, `OPERATOR_PASSWORD` — оператор; для CRM логин `admin` и `CRM_ADMIN_PASSWORD`. Не публикуйте `.env` и backup. [Инструкция запуска и эксплуатации](docs/RUNBOOK.md).

## Реализовано

- Pipecat SmallWebRTC, Silero VAD, микрофон, аудио, перебивания, mute и завершение; один активный голосовой разговор.
- Whisper large-v3-turbo q5 через whisper.cpp/Metal, Qwen3-4B-Instruct-2507 Q4/Metal и Qwen3-TTS Base с голосами Геннадий/Мария; Piper Denis — резерв; готовность после прогрева.
- Единое ядро чата и голоса, опубликованные знания, структурированные цены/расписание и локальная LLM.
- Черновик, подтверждение актуальной версии, транзакция, идемпотентность и защита пересечения слотов PostgreSQL EXCLUDE.
- Перенос/отмена по секретной ссылке конкретной записи. Имя/телефон не открывают чужую историю.
- CRM outbox: связанные Lead/Call/Task, восстановление неизвестного результата POST, повторы, pending_sync.
- Кабинет: обращения, статусы, расписание, история, знания, каталог, доступность сотрудника, очередь и метрики. Две роли.
- Живой перевод чата и голоса: два RTC peers и двусторонний media bridge; timeout и обратный звонок.
- Согласие, retention, удаление данных из всех копий приложения и обезличивание CRM. Аудио на диск не записывается.
- Установка, lock, manifest моделей с revisions/SHA256, миграции, backup и восстановление в тестовую БД.

## Новые режимы звонков

В кабинете откройте **Каналы звонков**: сайт, Telegram или SIP. Новые звонки принимаются только в выбранном режиме, текущий разговор продолжается. На сайте выберите Геннадия или Марию; Геннадий говорит на 10% быстрее с сохранением высоты тона.

Локальный SIP: Asterisk 22.11.0, сервер `192.168.1.119:15060`, Геннадий — `7001`, Мария — `7002`. Логин/пароль показываются только администратору в кабинете. Для iPhone/Android подходит [Linphone](https://www.linphone.org/en/download/). Вход в локальную АТС — своим SIP-аккаунтом, транспорт UDP. Клавиша 1 подтверждает согласие или текущую заявку, 0 запрашивает сотрудника. Обычный телефонный номер пока не подключён.

Telegram принимает обычные звонки отдельному пользовательскому аккаунту. API ID/hash, код и 2FA вводятся через кабинет; аккаунт помощника ещё нужно подключить. Звонить ему следует с другого аккаунта. В этом канале голос выбирается администратором до звонка.

Помощники поддерживают свободный разговор и используют последние 32 сообщения. Имя клиента сохраняется в памяти конкретной сессии. Они не объявляют бизнес-операцию выполненной без серверного подтверждения.
