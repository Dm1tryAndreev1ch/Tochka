# Дизайн интерфейса

При дальнейшей разработке UI следовать [основе дизайна Точки](docs/design/DESIGN_SYSTEM.md).

- Общие значения и компоненты находятся в `app/static/brand/tokens.css` и `components.css`. Использовать локальный Golos, спокойную светлую/тёмную палитру и мягкий ритм waveform.
- Утверждённый логотип в `app/static/brand/tochka-*.svg`: не менять геометрию и не накладывать на него текст. Для вспомогательных акцентов есть отдельный `signal.svg`.
- Продающий лендинг `/landing` и рабочий кабинет `/operator` раздельны. Не встраивать демо кабинета в лендинг.
- В кабинете только реальные данные и действия существующего API, с учётом разрешений, загрузки, пустых состояний и ошибок. Не заменять рабочие операции имитацией.
- Проверять изменения на мобильном и широком экране. Сохранять работу голосового клиента `/`, действующие серверные сценарии и чужие незакоммиченные изменения.
