# Загрузка моделей

`scripts/fetch_models.py` загружает закреплённый комплект моделей на Python 3.12/3.13, используя только стандартную библиотеку. Скрипт не устанавливает пакеты, не запускает службы и не меняет `.env`. Для запуска приложения нужны зависимости и native runtime, описанные в [LAUNCHERS.md](LAUNCHERS.md).

## Выбор комплекта

| Профиль | Содержимое | Полный размер файлов |
|---|---|---:|
| `mac-metal` | Whisper large-v3-turbo Q5, Qwen3-4B Instruct Q4_K_M, MLX Qwen3-TTS Base 0.6B 8-bit с tokenizer, Piper Denis для fallback, утверждённые образцы голосов | 4.775 GiB |
| `portable` | faster-whisper-small для CPU, Piper Denis с конфигурацией, Qwen3-4B Instruct Q4_K_M | 2.837 GiB |
| `llm-worker` | Только Qwen3-4B Instruct Q4_K_M GGUF | 2.326 GiB |

Это комплекты для runtime проекта. Экспериментальные модели ASR, VoiceDesign 1.7B и неиспользуемые варианты голосов не входят в них. Mac-профиль предназначен для Apple Silicon/MLX; переносимый профиль использует один голос Piper Denis. Загрузка файла сама по себе не проверяет совместимость драйвера или достаточность оперативной памяти.

Сначала можно посмотреть точный состав без сети, создания каталогов и чтения больших файлов:

```sh
python3 scripts/fetch_models.py --profile mac-metal --dry-run
python3 scripts/fetch_models.py --profile portable --dry-run
python3 scripts/fetch_models.py --profile llm-worker --dry-run
```

Загрузка выбранного профиля:

```sh
python3 scripts/fetch_models.py --profile mac-metal
python3 scripts/fetch_models.py --profile portable --model-dir /path/to/models
python3 scripts/fetch_models.py --profile llm-worker --model-dir /path/to/worker-models
```

На Windows используйте `py -3.12` вместо `python3`, например:

```powershell
py -3.12 scripts/fetch_models.py --profile portable --model-dir 'D:\Tochka\models'
```

Если LLM работает на другом компьютере, приложению достаточно речевых файлов:

```sh
python3 scripts/fetch_models.py --profile portable --exclude-llm
python3 scripts/fetch_models.py --profile mac-metal --exclude-llm
```

С `--exclude-llm` размеры составляют приблизительно 0.512 GiB и 2.449 GiB соответственно. На LLM-сервере используйте `llm-worker` без этой опции. `scripts/launch.py` умеет вызывать загрузчик через `--download-models` перед запуском и через `--download-only` для подготовки без запуска; подробнее в [инструкции launcher](LAUNCHERS.md).

## Пути и настройка

По умолчанию файлы помещаются в `<корень проекта>/models`. `--model-dir` задаёт другой каталог, включая путь с пробелами; относительный путь самого загрузчика разрешается от текущего рабочего каталога. Отсутствующий каталог создаётся при реальной загрузке. Для пути `/Volumes/...` на macOS целевой том должен быть смонтирован.

В существующем проекте веса могут быть вынесены на внешний диск, а `models/qwen3-4b-q4.gguf` и другие пути — быть символическими ссылками. Загрузчик не заменяет такие ссылки и не пишет сквозь них. Для этого случая укажите `--model-dir REAL_DIRECTORY`: физический каталог на смонтированном диске, где файлы имеют имена из таблицы ниже. Загрузка в каталог со ссылками останавливается с подсказкой; `--dry-run` тоже возвращает код 1, честно отмечая заблокированное назначение. Сами ссылки и внешние файлы сохраняются. Перед выбором другого пути проверьте, что это нужный каталог; рабочие ссылки удалять не требуется.

| Настройка приложения | Путь относительно `--model-dir` |
|---|---|
| `LLM_MODEL_PATH` | `qwen3-4b-q4.gguf` |
| `WHISPER_METAL_MODEL` | `whisper-turbo-metal.bin` |
| `WHISPER_MODEL` | `whisper-small` |
| `PIPER_MODEL` | `ru_RU-denis-medium.onnx` (рядом `.onnx.json`) |
| `NATURAL_TTS_MODEL` | `qwen3-tts-base-0.6b` |
| `VOICE_REFERENCE_DIR` | `voices` |

При самостоятельном вызове загрузчика выставьте подходящие пути в конфигурации приложения. Launcher с `--model-dir` передаёт их дочерним процессам. Голосовые образцы `male.wav`, `female.wav` и `metadata.json` копируются из утверждённых файлов `app/assets/voices` в `models/voices`; новые голоса не генерируются. Их контрольные суммы также закреплены в каталоге. После утверждённой замены исходных образцов нужно осознанно обновить соответствующие записи каталога.

Silero VAD поставляется в Python-пакете Pipecat как `pipecat/audio/vad/data/silero_vad.onnx`. Его устанавливают вместе с зависимостями; этот загрузчик отдельно его не скачивает. GGUF обслуживает установленный `llama-server`. Native библиотека Whisper Metal и MLX/Piper/ONNX runtimes также устанавливаются отдельно.

## Проверка и восстановление загрузки

Список файлов, полные commit SHA, размеры и SHA-256 находятся в [model-download-catalog.json](../scripts/model-download-catalog.json). Все скачиваемые URL используют закреплённый commit, а не `main`. Существующий файл пропускается только после совпадения размера и SHA-256. `--dry-run` пишет «present, not yet verified» и не утверждает, что уже лежащие на диске веса проверены.

Каждый новый файл сначала пишется рядом в `.part`. Готовый файл заменяется атомарным переименованием только после успешной проверки полного SHA-256 и размера. Обрыв или несовпадение суммы не заменяет предыдущий файл. Загрузка набора последовательная: уже проверенные файлы сохраняются при ошибке следующего; весь профиль не является одной атомарной транзакцией. Launcher не продолжает запуск после ошибки загрузчика.

Рядом с частичным файлом сохраняется `.part.json` с ETag, адресом закреплённой версии, размером и SHA-256 префикса. При повторном запуске загрузчик проверяет префикс и запрашивает `Range`/`If-Range`. Несовпадение ETag или Content-Range приводит к безопасному перезапуску файла; ответ `200` вместо `206` записывается с нуля. Без сильного ETag файл скачивается заново. После жёсткого завершения процесса последний префикс может не совпасть с checkpoint — тогда он также скачивается заново.

До начала проверяется свободное место для недостающих файлов с учётом проверенных частичных загрузок и резервом 64 MiB. При замене старый файл остаётся на диске до окончания загрузки, поэтому требуется место для новой копии. Скрипт повторяет временные сетевые ошибки; параметры `--timeout 60 --retries 3` задают таймаут отдельной сетевой операции и число повторов после первой попытки. Таймаут не ограничивает общее время всей загрузки. При нехватке места выберите другой `--model-dir`; при сетевой ошибке повторите ту же команду. TLS-проверка не отключается.

Файл `<model-dir>/download-manifest.json` записывает проверенные артефакты, размеры, контрольные суммы, закреплённые revision, исходные адреса, лицензии и время проверки. Он обновляется после каждого файла и сохраняет записи предыдущих профилей. Это журнал результата: источником ожидаемых сумм остаётся checked-in каталог. Корневой `model-manifest.json` и прежние download-скрипты не меняются. Проверка SHA-256 подтверждает совпадение с доверенным каталогом, но не является независимой подписью издателя модели.

`.fetch-models.lock` не допускает одновременные запуски этого загрузчика в одном каталоге. Не запускайте параллельно старые download-скрипты. После аварийного завершения удалите оставшийся lock только после проверки, что прежний процесс действительно остановлен. При повреждённом output manifest сохраните его отдельно и повторите запуск: файлы моделей будут проверены заново. Не удаляйте рабочие модели для исправления manifest.

## Источники закреплённых файлов

- [Qwen3-4B Instruct GGUF, преобразование Unsloth](https://huggingface.co/unsloth/Qwen3-4B-Instruct-2507-GGUF/tree/a06e946bb6b655725eafa393f4a9745d460374c9): Apache-2.0; имена и суммы перенесены из имеющегося manifest проекта.
- [Whisper Turbo для whisper.cpp](https://huggingface.co/ggerganov/whisper.cpp/tree/5359861c739e955e79d9a303bcbc70fb988958b1): MIT; LFS SHA-256 и размер проверены через API закреплённой версии 13.10.2026.
- [faster-whisper-small](https://huggingface.co/Systran/faster-whisper-small/tree/536b0662742c02347bc0e980a01041f333bce120): MIT; четыре файла runtime из manifest проекта.
- [Piper Denis](https://huggingface.co/rhasspy/piper-voices/tree/c10ece1aade47bb51c153c893d14e5bf8e5b7117/ru/ru_RU/denis/medium): MIT для repository, CC0 для исходного набора по model card. Лицензия движка Piper проверяется отдельно от весов.
- [MLX Qwen3-TTS Base 0.6B 8-bit](https://huggingface.co/mlx-community/Qwen3-TTS-12Hz-0.6B-Base-8bit/tree/50f45ef0047cde7e84c2ef04326acb8ada2436a7): Apache-2.0; все 12 файлов модели и tokenizer из manifest проекта.

Для обновления модели сначала пересмотрите source revision, состав файлов, совместимость и лицензии; затем обновите размер и ожидаемый SHA-256 в каталоге. Сумму нельзя автоматически подменять значением повреждённого скачанного файла.

Изолированные тесты без сети и весов: `python3 -m unittest discover -s tests -p test_fetch_models.py -v`.
