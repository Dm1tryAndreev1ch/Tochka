# Анализ проекта — 13 октября 2026

Локальное приложение выполняет сквозные сценарии: разговор, опубликованные знания, подтверждённая запись, PostgreSQL/EspoCRM и перевод сотруднику. В этой итерации добавлены новые русские голоса, более точное распознавание, память диалога, выбор канала звонков и SIP. Полная внешняя приёмка из исходного плана ещё не завершена.

## Сделано и проверено

| Возможность | Фактическое состояние |
|---|---|
| Геннадий | Исходная синтетическая запись сохранена. Речь ускорена на 10% с сохранением высоты тона; это проверено сигналом с известной частотой и финальным звуком. |
| Мария | После отклонения прежних вариантов пользователь выбрал новый низкий бархатный тембр по образцу. Эталон `maria-velvet` установлен в рабочий женский профиль; образец на сайте обновлён. Полный разговор с ним на телефонах ещё требует проверки. |
| Распознавание | whisper.cpp/Metal large-v3-turbo q5, полный контекст, beam search; сегменты до 20 секунд. Старый ускоренный сокращённый контекст отключён. |
| Поток голоса | PCM-поток, сохранение границ сэмплов, отмена HTTP/ASGI синтеза и освобождение очереди. Исправлен зависавший слот после прерывания. |
| Диалог | Реальная Qwen3-4B отвечает своими словами, объясняет и поддерживает разговор. История — последние 32 сообщения; явно названное имя сохраняется отдельно в сессии. |
| Память и удаление | Имя сохраняется после отмены/подтверждения черновика и очищается при удалении персональных данных. Между клиентскими сессиями память не объединяется. |
| Режимы | Администратор переключает сайт / Telegram / SIP. Новые звонки принимаются в выбранном канале, уже начатый разговор продолжается. Чат остаётся доступным. Есть ревизии настроек и audit. |
| Telegram | Реализован отдельный процесс с Telethon/PyTgCalls/NTgCalls, входом по API ID/hash, коду и 2FA; двусторонний PCM-адаптер для обычных пользовательских звонков. Пользователь отложил подключение аккаунта; реальный Telegram-звонок не проверен. |
| SIP | Asterisk 22.11.0 собран из официального исходника с проверкой SHA256. Защищённые аккаунты, два номера помощников, DTMF, AudioSocket и двусторонний RTP. Два настоящих SIP/RTP-звонка с синтетическим микрофоном прошли. |
| Телефон / сайт | LAN HTTPS, публичный сертификат и инструкции iPhone/Android, QR-код, выбор голоса и восстановление звука. Пользователь ранее подтвердил работу звука на обоих телефонах; улучшенная версия требует повторного физического прослушивания. |
| Бизнес-операции | Черновики, явное подтверждение, ревизии, идемпотентность, защита пересечения слотов, секретные ссылки управления и CRM outbox. |
| Проверки | 53 pytest, 11 Playwright, Ruff и проверка синтаксиса JS; реальная модель, настоящие БД/CRM, RTC-микрофон и звуковой мост. Это не нагрузочное испытание и не проверка всех физических устройств. |

Реальный диалог с Марией: знакомство и содержательный ответ — 5,39 с; вопрос об имени — 1,21 с; объяснение различия услуг — 4,12 с. Это три отдельных наблюдения, не p50/p95. STT на шести синтетических фразах занял 1,35–1,76 с. Первый фрагмент прогретого Base TTS в компонентной проверке — примерно 0,28–0,37 с. Серверные метрики не равны задержке до звука на телефоне.

Доказательства: `artifacts/conversation-live-validation.json`, `artifacts/metal-turbo-stt-benchmark.json`, `artifacts/voice-profile-validation/metrics.json`, `artifacts/sip-acceptance/results.json`, `artifacts/browser-results.json`. Записи SIP в этой папке содержат только сгенерированный тестовый голос. Реальные разговоры приложение на диск не записывает.

После выбора низкого бархатного тембра Марии повторно прошли два браузерных HTTPS-звонка, проверены три новые фразы рабочего TTS и воспроизведение обновлённого образца на мобильной вёрстке. Отдельные результаты сохранены в `artifacts/maria-velvet/`; предыдущий полный браузерный отчёт не перезаписан. Автоматическая транскрипция не заменяет слушательскую оценку дикции в произвольном разговоре.

## Что ещё не доработано или требует исправления

| Приоритет | Проблема / ограничение | Что требуется |
|---|---|---|
| P0 — перед внешним запуском | Telegram не подключён к реальному аккаунту | Войти через кабинет с отдельным аккаунтом помощника; позвонить ему с другого аккаунта, проверить оба направления, перебивание, отказ/потерю связи и повторный звонок. Импорт SDK и готовый код не заменяют такую проверку. |
| P0 — качество | Нет приёмки полных разговоров с новым голосом Марии и новой STT на живой речи | Повторить разговор на iPhone и Android, включая имена, +375, даты, исправления, фоновые шумы и конец длинной фразы. Тембр Геннадия одобрен пользователем; новый низкий бархатный тембр Марии выбран по короткому образцу. |
| P0 — голосовой диалог | История сохраняет сформированный ответ до подтверждения реально услышанного текста | Добавить playback acknowledgements и фиксацию услышанного фрагмента при перебивании. См. `app/dialogue.py:74` и `app/voice.py:199`. |
| P0 — скорость | Целевые p50/p95 исходного плана не доказаны | Измерить не менее 300 реплик, отдельно FAQ/свободный диалог/операции; учитывать ошибки, cold/warm и момент слышимого звука. Текущая локальная модель иногда отвечает несколько секунд. |
| P0 — сеть | Нет проверенного доступа через мобильный интернет | Домен/доверенный публичный TLS, NAT/TURN, ограничения соединений и проверка внешних сетей. Сейчас согласованный доступ — одна Wi-Fi сеть. |
| P1 — SIP | Проверка выполнена синтетическим SIP-клиентом на Mac | Проверить регистрацию и звонки в Linphone на обоих телефонах. Прямой SIP-перевод на внешнюю АТС/номер не реализован; сотрудник подключается через существующий браузерный мост. |
| P1 — телефония | Нет обычного телефонного номера и SIP-транка | Выбрать оператора и подключить оплачиваемый номер, затем проверить входящие внешние звонки. Локальная АТС не создаёт публичный номер автоматически. |
| P1 — защита сети | Локальный SIP использует UDP/RTP без шифрования | Для внешнего или недоверенного окружения подготовить TLS/SRTP и проверку сертификатов. Публикация портов сама по себе не подтверждает безопасный интернет-выпуск. |
| P1 — эксплуатация | Launcher запускает дочерние службы, но не имеет полноценного supervisor | Добавить контролируемый перезапуск процессов, готовность после восстановления БД, сохранённые причины отказа, мониторинг места и длительный прогон. `scripts/run.py:187` ожидает gateway; отдельный упавший worker сам не перезапускается. |
| P1 — знания | Передаётся ограниченный текст опубликованных документов | Нужны поиск по большой базе, отбор релевантных фрагментов и источники ответа. В `app/models.py:287` факты ограничены 6000 символами; это не полноценный RAG. |
| P1 — память | Нет памяти между звонками и полноценного профиля клиента | Сейчас имя и контекст принадлежат конкретной сессии. Для постоянной памяти нужна отдельная идентификация клиента, согласованный срок и управляемое удаление; одного имени/телефона недостаточно для доступа к истории. |
| P1 — масштаб | Один общий голосовой слот, одна организация и один ресурс расписания | Очередь/пул работников, несколько сотрудников/ресурсов и tenant isolation нужны для большего объёма. См. `app/voice.py:226`. |

| P1 — регрессии модели | Нет большого набора человеческих и негативных сценариев | Проверить выдуманные факты, prompt injection, отрицания, спорные подтверждения и потерю связи. Сохранить версии prompt/знаний и критерии приёмки. |
| P2 — команда | Две общие роли с паролями | Индивидуальные аккаунты, более точный RBAC и actor ID в audit; управление несколькими организациями не реализовано. |
| P2 — платформы | Проверен текущий Mac M4 / Python 3.12 | Чистая установка, Windows/Linux/split profile, английский, автозапуск после перезагрузки и обновления ещё требуют отдельных прогонов. |
| P2 — документация/доставка | Нет отдельного подписанного приложения или установочного пакета | Сейчас это локальный веб-сервис со скриптами запуска. Нужны схема обновлений, пакет, поддерживаемые версии ОС и каталог лицензий зависимостей для выбранного способа распространения. |

## Исправления, выявленные в этой итерации

- Потеря качества ASR на сокращённом контексте — заменена полным контекстом и более сильной моделью.
- Прежние тембры Марии отклонены пользователем. Из трёх новых вариантов выбран низкий бархатный; он установлен вместе с соответствующим текстом эталона и образцом на сайте.
- Прерывание синтеза оставляло занятую очередь — исправлено и воспроизведено тестами ASGI и реальным HTTP-разрывом.
- Нехватка места остановила Docker — удалены только заменённые исследовательские модели; рабочие веса, записи голосов и данные БД сохранены. Зависимости и Python-кеш размещены вне iCloud.
- SIP-переадресация через OrbStack, приватный адрес RTP в SDP и таймаут AudioSocket во время пауз — исправлены; прошли два двусторонних SIP-звонка.
- Новое поле памяти первоначально не очищалось privacy-функцией — тест выявил утечку, очистка исправлена, регрессия прошла.

G0 соответствует проверенному локальному демонстрационному контуру. G1 остаётся открытым из-за внешней сети, качества, SLO и программы пилота. G2 реализован частично и проверен двумя SIP-сценариями; полная программа DTMF/переводов/сбоев ещё не закрыта. G3 не выполнен: внешнего телефонного номера нет.
