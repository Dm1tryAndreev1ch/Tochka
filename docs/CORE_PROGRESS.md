## Реализованные изменения, требующие итоговой интеграционной приёмки

- readiness: деградация БД HTTP503 с диагностикой вместо ошибки500; восстановление проверено.
- retry/backoff фоновой очистки и CRM, безопасные причины отказа.
- supervisor своих дочерних процессов, bounded retry, process status, rotation10MiB×3.
- проверка фактов: телефон только из опубликованного источника; FAQ-цитаты проверяются сервером.
- имя из памяти сессии, бюджет контекста через tokenizer llama.cpp с отсечением старой истории.
- handoff по голосовой просьбе, единое серверное действие, озвучивание timeout/disconnect.
- delivery: generated_text отдельно; в LLM-history только подтверждённый сыгранный текст; поздняя квитанция после interruption не дописывает остаток.
- длинная речь: части20с с overlap и сборкой; один финальный Transcript; верхняя граница90с с объяснением.
- очередь: CallQueue и admission gate до VAD/STT; веб/SIP admission в процессе проверки.
- новый текущий LAN172.20.10.3 вместо192.168.1.119; CA сохранён, private TLS/CA keys перенесены в ~/.cache/voice-desk/private. Launcher обновляетLAN на следующем старте.
