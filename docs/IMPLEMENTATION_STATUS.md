# Проверенная локальная версия — 13 октября 2026

На MacBook Air M4, macOS 26.6, Python 3.12 работают FastAPI/Pipecat, PostgreSQL/EspoCRM, whisper.cpp/Metal large-v3-turbo q5, Qwen3-4B Q4 и MLX Qwen3-TTS Base. Геннадий использует одобренный синтетический эталон и темп 1.10 с сохранением высоты. Для Марии пользователь выбрал вариант 1 — низкий бархатный: установлен эталон `maria-velvet`, обновлён образец на сайте и перезапущен речевой сервис. Основные рабочие веса занимают около 4.8 ГБ; исследовательская VoiceDesign используется отдельно для подбора.

## Новое поведение

- Память последних 32 сообщений и явно названного имени внутри сессии; name-memory очищается privacy-функцией. Нет объединения историй разных клиентов.
- Сайт / Telegram / SIP выбираются администратором, сохраняются с ревизией и audit. Смена действует на новые звонки, текущий продолжается. Чат доступен независимо.
- Telegram: изолированный пользовательский MTProto/WebRTC-адаптер с формой API ID/hash, кода и 2FA. Пользователь отложил подключение аккаунта; он ещё не авторизован, реальная связь Telegram не принята.
- SIP: два номера 7001/7002, один общий голосовой слот, согласие перед сохранением текста, 1 — подтверждение, 0 — запрос сотрудника. До согласия пользовательские реплики/контакты не сохраняются.
- Для AudioSocket передаётся тишина между ответами, чтобы ожидание ASR/LLM не разрывало звонок.
- Node dependencies, Python virtualenv/bytecode и секреты новых адаптеров — вне iCloud. Неиспользуемые исследовательские веса удалены после нехватки места.

## Ограничения приёмки

G0 — проверенный локальный контур. G1 не закрыт: нет полного испытания естественности, слышимой p95-задержки, playback acknowledgements, внешней сети и пилота. G2 частично реализован и имеет два SIP-сценария; программа DTMF/перевода/сбоев целиком не пройдена. G3 не закрыт: обычного телефонного номера и оператора нет.

Пользователь подтвердил первоначальный звук на физических iPhone/Android и одобрил Геннадия. После замены Марии и ASR нужны повторные разговоры. Нет человеческого WER/MOS, 300 latency-измерений, 8-часового soak и 50 добровольческих звонков.

Для выбора Марии подготовлены три новых синтетических эталона и ответы с ними через рабочий Base TTS: низкий бархатный, спокойный средний, живой и тёплый. Файлы и параметры находятся в `artifacts/maria-options-20261013/`; 6/6 фраз совпали с нормализованной транскрипцией Whisper. Не завершившиеся дубли отброшены. Пользователь одобрил низкий бархатный тембр по образцу, после чего он установлен в активный женский профиль. Геннадий сохранён: эталон проверен по SHA256, мужские метаданные и образец не менялись. Выбор тембра не заменяет приёмку полного разговора на телефонах.

История сохраняет сформированный ответ до подтверждения реально услышанного фрагмента. SIP пока без TLS/SRTP, интернет/NAT/TURN не принят. Память принадлежит сессии, организации/ресурс расписания по одному, роли две. Полное восстановление CRM/новых адаптеров и автоматический supervisor требуют доработки.
